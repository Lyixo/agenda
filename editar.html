✓ Verbunden

Einmal pro Gerät: Damit dieses Handy veröffentlichen darf, braucht es einen eigenen Zugangsschlüssel. Er bleibt nur in diesem Browser.

  1. Öffne github.com → neuer Fine-grained Token (angemeldet als dein Konto).
  2. Name z. B. Agenda iPhone, Ablauf 90 Tage.
  3. Repository access: Only select repositories → agenda.
  4. Permissions → Contents: Read and write. Sonst nichts.
  5. Generate token, kopieren und hier einfügen.
